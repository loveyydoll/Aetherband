# Aetherband

> **Make sound your own. Keep the tools open.**

**Aetherband is an open-source DAW with a bigger ambition: to bring music production, live experimentation, precision audio work, and programmable sound into one creative environment.**

Imagine a studio that doesn't stop at recording tracks and turning knobs. Build a song, reshape its sound, perform ideas in real time, and—over time—make the tools themselves part of the instrument. Aetherband is being built for musicians who want to explore and developers who want to open the hood.

## One studio. More ways to create.

- **Produce** — a foundation for recording, arranging, editing, and mixing.
- **Perform** — a future-facing space for clips, improvisation, and hands-on control.
- **Sculpt sound** — an evolving direction for synthesis, effects, modulation, and spatial audio.
- **Build your own tools** — an open architecture designed to grow toward visual programming and custom creative workflows.

The goal isn't to copy one existing DAW. It's to bring these ways of working closer together—and leave room for ideas nobody has built into a conventional studio yet.

## The project today

Aetherband is **early alpha**: an evolving prototype, not a production-ready DAW. The project currently has a Rust audio-engine foundation, a versioned C ABI, and a Flutter desktop frontend using Dart FFI. Core workflows are still being connected and verified; recording, MIDI, instruments, effects, project saving, and export should not be assumed complete.

This is the beginning, not the finished studio. Features and direction will evolve in public, and the long-term vision is not a claim that those capabilities exist today.

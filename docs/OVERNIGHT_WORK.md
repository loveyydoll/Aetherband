# Aetherband Windows audio and DAW foundations

Implement the user's Windows-only audio repair, original HypnoSynth, and core DAW workflows in one PR. Preserve the existing UI and conflicting Desktop checkout; `sources/` is read-only. Soundcraft reuse is limited to its MIT-licensed ADSR envelope, with attribution and licence in `third_party/soundcraft/`. Rust remains the real-time engine and Flutter/Dart the desktop UI.

Branch: `feat/hypnosynth-daw-foundations`. PR: [#33](https://github.com/loveyydoll/Aetherband/pull/33), open and unmerged. Keep all work in this one PR and publish it without merging.

## Implemented in the current working tree

- Windows output uses native CPAL formats, processes complete callback buffers, reports stream errors, and releases stream resources safely. Output-device changes restore synth, transport and mixer configuration, rescale clip positions for the new sample rate, and restart stopped at the beginning.
- HypnoSynth is an original polyphonic instrument with three authored presets, live keyboard, performance controls, panic, tempo/metronome, and an editable, persisted 16-step note/rest pattern that plays through the callback and offline render. The musical references informed original sound design; no recordings or patches were copied.
- Sessions start empty and connect imported audio, timeline movement with default beat snapping and a free-placement toggle, mixer controls, session save/reopen, Windows input recording, stereo WAV export, Space/R transport shortcuts and bar/timeline seeking to the Rust engine through ABI 0.12.0 with configurable 2–7/4 time signatures and meter accents through the Dart worker isolate. The Region menu splits and joins source-contiguous audio regions and trims a selected region to the stopped playhead; source-bounded changes are mixed, moved, saved and restored. Schema v6 adds movable, deletable HypnoSynth pattern regions with note/rest data; schemas v1-v5 remain readable.
- PCM and IEEE-float WAV files render measured peak waveforms loaded off the UI isolate; unsupported formats show an explicit unavailable state.
- Undo/redo restores audio and HypnoSynth pattern clip moves, step-note edits, pattern insertion/removal, region splits/joins and trims through the native engine and session model, with Ctrl+Z/Ctrl+Y and generic Edit-menu actions. Pattern copy/paste/duplicate/cut also enters chronological history. Split audio regions participate in copy/paste and duplication.
- Track > Add Instrument Track creates a single named HypnoSynth arrangement track, which can be selected, renamed, deleted and saved/reopened. Its mixer gain, pan, mute and solo reach the real-time engine and offline mixdown. Insert Pattern places the editable 16-step note/rest phrase at the playhead; selecting a pattern lets the step editor update that region, and the clip can move, delete, copy, cut, paste at the playhead, or duplicate adjacent to itself. Pattern edits update the native scheduler and session model. Regions play through the real-time callback and offline mixdown. Session schema v6 stores pattern IDs, notes and timeline positions. Independent MIDI tracks and standard MIDI file interchange remain unimplemented.
- Only the Soundcraft ADSR code was reused. No other language showed a concrete subsystem advantage for this change.
